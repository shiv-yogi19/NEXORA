NEXORA is Offline

Your mobile server is currently unavailable. Start the server on your phone to reconnect to your private media library.

How to bring the server back
  1. Open Pydroid 3 on your phone.
  2. Open nexora_server.py and run it (or run run from its menu).
  3. Check that your Cloudflare Tunnel is also running.
  4. Tap Retry Connection here.

The connection can also fail because of your network, DNS, the tunnel, or a TLS problem, so a stopped server is only one possible cause.
